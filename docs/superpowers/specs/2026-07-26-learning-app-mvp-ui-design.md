# 本地学习应用 MVP UI 设计规范

日期：2026-07-26  
状态：已确认  
范围：Android 手机竖屏 MVP

## 1. 设计目标

界面采用沉浸式、简约、低打扰的产品方向。用户打开应用后，应尽快进入当前最有价值的动作：继续学习，或者从已安装知识库中选择学习内容。

MVP 不通过堆叠按钮、分类、运营组件或装饰主题制造完整感。所有页面使用统一的纯白编辑感视觉体系，优先保证内容清晰、入口明确和学习过程连续。

产品界面统一使用“知识库”作为用户可见名称；代码、数据库和接口仍可使用稳定的 `pack` 技术命名，不因文案改变而重命名底层模型。

## 2. MVP 页面范围

第一阶段只设计和实现以下核心界面：

1. 我的知识库
2. 知识库市场
3. 知识库详情
4. 学习与复习
5. 当前知识库内容搜索
6. 学习页右上角更多弹窗
7. 全局左上角菜单弹窗

登录使用单独的轻量全屏页面；购买从详情页唤起微信支付；下载与安装状态直接显示在详情页主按钮区域；普通错误使用就地提示，必须阻断流程的错误才使用确认弹窗。这些状态不扩展成独立内容体系。

MVP 不实现主题切换、评分评论、相关推荐、优惠券、倒计时、排行榜、社区、复杂数据大屏或多层内容目录。

## 3. 启动与导航

### 3.1 启动路由

- 存在未完成的学习任务：直接进入学习页，并继承上一次任务；不会因跨天而累积多天的新任务。
- 不存在未完成的学习任务：进入“我的知识库”。即使用户已安装知识库，也不会自动跳到知识库市场。

### 3.2 常规页面导航

常规页面底部只保留一个悬浮胶囊导航，包含 **三个** 触控区（左 Tab、中间操作、右 Tab）：

- **首页**（对应「我的知识库」页；产品文案可简写，路由不变）
- **上传**（中间「+」；阶段 4 占位，点击就地提示「功能开发中」；后续承载用户上传/导入类能力）
- **资料**（对应「知识库市场」页）

不使用传统贴底 Tab 栏。页面顶部不重复显示页面名称，只保留当前页面必需的操作图标。

### 3.3 沉浸页面导航

知识库详情页和学习页隐藏底部胶囊导航：

- 详情页左上角提供返回按钮。
- 学习页不显示左上角菜单，右上角使用“更多”按钮承载低频操作。

## 4. 统一视觉语言

### 4.1 色彩

所有页面采用同一套纯白编辑感配色，不在学习页单独使用纸张色：

| 用途           | 色值      |
| -------------- | --------- |
| 页面背景       | `#F5F6FA` |
| 卡片与浮层     | `#FFFFFF` |
| 主要文字       | `#202228` |
| 次要文字       | `#6F737D` |
| 弱提示与分割   | `#E9EAF0` |
| 主强调色       | `#6D70E8` |
| 价格与重要状态 | `#EF7058` |

不为不同页面增加独立主题。图标优先使用深灰或主强调色，避免大面积高饱和颜色。

### 4.2 版式

- 使用足够留白、圆角白色卡片和轻微阴影组织内容。
- 同一屏只保留一个最重要的主操作。
- 不用页面大标题占据首屏空间。
- 主要信息靠字号、字重和间距建立层级，不依赖大量边框。
- 文案使用中文直白表达，图标不够明确时必须配文字。

### 4.3 触控与适配

- 触控热区不小于 44×44 dp。
- 正文允许系统字体缩放，重要操作文案不能被截断。
- 以 Android 8 及以上手机竖屏为主要目标。
- 小屏设备优先保证主内容和主操作可见；次要信息允许换行，不缩小到难以阅读。
- 底部固定操作必须避开系统安全区和手势区域。

## 5. 我的知识库

### 5.1 顶部

- 左上角：菜单按钮。
- 右上角：搜索按钮。
- 不显示“我的知识库”页面标题。

搜索范围仅为已安装知识库的名称，不搜索知识库内部内容。

### 5.2 首页内容

首屏使用一张概览卡片表达当前学习状态和继续学习入口。卡片下方展示已安装知识库列表。

每个知识库条目只显示：

- 知识库名称
- 必要的简短进度或状态
- “开始学习”或“继续学习”主动作

本页不增加年级、版本等筛选器。用户安装的知识库数量通过名称搜索解决查找问题。

### 5.3 空状态

没有已安装知识库时，保留页面结构，显示一条简短说明和“去知识库看看”按钮。按钮切换到底部“知识库”页面，不创建额外引导流程。

## 6. 知识库市场

### 6.1 顶部与搜索

- 右上角显示搜索按钮。
- 不显示页面标题。
- 搜索匹配知识库后，自动切换到对应一级分类、二级分类和版本筛选，并将目标知识库滚动到可见位置并短暂高亮。
- 若有多个匹配结果，先显示简洁结果列表；选择结果后再跳转定位。

### 6.2 分类结构

一级分类位于顶部横向滚动区域：

- 全部
- 小学英语
- 初中英语
- 高中英语
- 考研英语

二级分类位于左侧。小学英语下展示“全部年级”和一至六年级；其他一级分类按实际发布内容提供对应二级项，但沿用同一组件，不新增交互层级。

右侧内容区顶部使用紧凑版本筛选，例如：

- 全部版本
- 人教版
- 外研版
- 译林版

内容类型和册别不继续成为导航层级，而是在知识库卡片上以“词汇”“短句”“上册”“下册”等标签展示。

### 6.3 列表行为

切换一级分类时，二级分类重置为该分类的“全部”；切换二级分类时保留当前版本筛选。筛选结果为空时只显示清晰空状态，不自动切换到其他分类。

点击知识库卡片进入详情页。

## 7. 知识库详情

详情页从知识库市场进入，隐藏底部胶囊导航，结构保持最小化：

1. 返回按钮和轻量分类上下文
2. 封面、知识库名称、年级、教材版本、册别和内容类型
3. 内容数量、资源大小、更新时间
4. 包含内容概览
5. 少量内容示例，可试听示例语音
6. 底部固定价格和唯一主操作

主操作根据真实状态切换文案和行为：

```text
未购买：立即购买
支付待确认：确认中
已购买未下载：下载
下载中：显示进度并允许取消
已下载未安装：安装
已安装：开始学习或继续学习
```

价格必须来自服务端订单信息，客户端示例价格不是业务真值。已经拥有权益时不再显示购买入口。

MVP 不显示评分、评论、推荐、促销和复杂商品说明。

## 8. 学习与复习页

### 8.1 页面骨架

- 隐藏底部胶囊导航。
- 顶部仅保留轻量进度信息和右上角更多按钮。
- 视觉中心为单张学习卡片。
- 第一阶段不显示章节、分组或目录选择，进入知识库后直接开始或继续学习。

### 8.2 两阶段作答

学习卡片先显示题面。用户点击卡片空白区域后显示答案；点击例句中的英文单词只打开点词弹窗，不触发答案展示。

本规范只确定答案区的展开方式、信息层级和交互边界，不提前规定单词、短句等内容类型必须包含哪些展示字段。具体字段、必填性、缺省行为以及不同内容类型的渲染映射，在后续学习包协议设计中统一确定；UI 根据协议提供的数据按受控组件渲染。

答案显示后，底部出现三个固定反馈按钮：

- 忘记
- 模糊
- 记得

每个按钮下方显示本次点击后预计再次复习的动态间隔，例如“10分钟后”“2天后”“5天后”。间隔由调度算法计算，界面不写死固定天数。

选择反馈后立即保存本地学习状态并进入下一张卡片。网络不可用不阻塞学习。

### 8.3 语音、图片与点词

- 主学习内容所需图片和语音随知识库下载。
- 例句中的任意英文单词可点击。
- 点词弹窗离线显示词义、词性和必要解析。
- 点词弹窗中的单词语音首次点击时下载并缓存；下载失败时保留文字解析并提供重试。
- 播放、加载和失败状态使用同一个语音按钮表达，不增加额外页面。

### 8.4 找回忘记内容

用户可以从学习页右上角更多菜单进入“搜索当前知识库”。搜索范围只包括当前知识库的主学习内容。

搜索结果允许用户将遗忘内容重新加入复习。加入成功后给出轻量反馈；重复加入时不创建重复任务。

### 8.5 更多菜单

右上角更多弹窗只包含：

- 搜索当前知识库
- 切换已安装知识库
- 基础学习设置

切换知识库时先保存当前任务位置，再进入所选知识库。弹窗不承载统计、账号或购买功能。

## 9. 全局菜单抽屉

常规页面左上角菜单采用从左侧滑出的白色抽屉，宽度约为屏幕的 86%，右侧保留半透明深色遮罩。点击遮罩、向右滑动抽屉或按 Android 返回键均可关闭；关闭后返回原页面和原滚动位置。

抽屉顶部只显示监护人账号头像、账号名称和脱敏手机号，点击后进入账号信息（阶段 4 可 mock 占位；阶段 5 登录后接真数据）。顶部不重复展示“已安装知识库、已学习内容、待复习”等学习摘要，这些信息只属于「我的知识库」页面。

**常用功能**（图标宫格，阶段 4 重构新增；未开放项点击提示预留文案，不做灰色假跳转）：

- 记得攻略、真题库、兑换码、关注我

**列表菜单**（无分组标题，按顺序排列）：

- 下载管理
- 收藏本（点词收藏的词形列表；`packId + surfaceForm`）
- 基础设置
- 关于应用
- 联系我们（预留）

阶段 5–6 再补：学习统计、订单与权益等账号相关入口。

抽屉不放会员广告、连续学习天数、日历热力图，也不重复胶囊「首页 | 资料」两个主导航。已实现入口可点击；预留入口仅 Alert 说明，不假装完成。

## 10. 状态与错误反馈

- 加载：优先使用保持版式稳定的骨架状态，避免整屏转圈。
- 空数据：说明当前没有内容，并只给一个可执行动作。
- 弱网：知识库列表和商品信息可重试；已安装内容继续可用。
- 支付：客户端支付完成不等于购买成功，必须等待服务端确认权益。
- 下载：显示进度、暂停或失败原因；失败后从可恢复位置重试。
- 权益失效或校验失败：不删除本地学习状态，提示联网重新校验。
- 数据保存：作答先写本地；同步失败不打断下一张卡片。

错误文案必须说明发生了什么以及用户能做什么，不直接展示服务器错误码或技术堆栈。

## 11. 动效原则

- 页面转场和卡片答案展开使用短而轻的动效，建议 150–220 ms。
- 用户开启系统“减少动态效果”后关闭非必要位移与缩放。
- 不使用连续漂浮、闪烁、彩带或游戏化奖励动画。
- 作答后的下一张卡片切换必须快速，不能等待云端同步完成。

## 12. 验收标准

### 12.1 主流程

- 有未完成进度时，冷启动直接恢复到正确学习位置。
- 无未完成进度时，冷启动进入“我的知识库”。
- 两个常规页面可以通过悬浮胶囊互相切换。
- 知识库搜索可以定位到正确分类和目标卡片。
- 已购买知识库可以完成下载、安装并进入学习。
- 学习页的点词操作不会误触发答案展示。
- 三个反馈按钮都显示动态复习间隔，并能正确进入下一张。
- 当前知识库搜索可以将内容重新加入复习。

### 12.2 视觉与易用性

- 悬浮胶囊为「首页 | + | 资料」三触控区（中间上传为已确认占位，见 §3.2）。
- 学习页和详情页不显示底部胶囊。
- 所有页面保持统一白色编辑感，不出现独立复习主题。
- 320 dp 宽度下主操作可见、文字不重叠。
- 系统字体放大后，购买、继续学习和三个复习按钮仍可完整识别。

## 14. MVP 边界原则

> 首屏帮助用户继续学习，分类帮助用户找到正确教材，详情页帮助用户完成一次购买，学习页只帮助用户记住内容。任何不能直接服务这四件事的界面元素，第一阶段都不加入。
