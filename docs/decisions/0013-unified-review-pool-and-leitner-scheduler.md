# 0013 学习包浏览与统一复习池（Leitner 调度）

日期：2026-08-06  
状态：**已确认**  
关联：ADR [0008](./0008-pack-protocol.md)（`knowledgeId`）、[0012](./0012-card-type-registry.md)（`reviewMode` / 书库呈现）；替代/废止移动端 **学习包内 SM-2 三按钮** 产品行为（`packages/domain/review-scheduler.ts` 仍可在迁移期保留，见 §9）

---

## 1. 背景

### 1.1 问题

- 现行 **SM-2 三按钮**（忘记 / 模糊 / 记得）在学习包内调度间隔；首次「模糊」与「记得」间隔相同，用户难以理解（2026-08 实机反馈）。
- 学习 session 按「到期复习 + 每日新卡」生成队列，与「全书连续学、随时再打开」的期望不一致。
- 多学习包词汇需汇总复习，但 `learning_states` + 按 pack 的 study session 模型不利于 **跨包统一复习计划**。

### 1.2 目标

| 目标 | 说明                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------- |
| G1   | **学习包**只负责「认内容 + 是否加入复习池」，**不算间隔**                                       |
| G2   | **统一复习池**跨 pack 汇总，**单 `knowledgeId` 一条记录**                                       |
| G3   | 复习调度 **可解释**（档位 + 固定间隔），「还不熟」统一 **明天再见**                             |
| G4   | 学习包 **永远展示全部词**，仅 **书签** 记录上次位置，可随时从头再开                             |
| G5   | 复习入口：**底栏中间蓝色「+」Tab**（承接原加号位）                                              |
| G6   | **每日复习词数由用户自行设置**；入池 **不设上限**，但 **统计** 今日新加入复习词数供后续面板展示 |

### 1.3 非目标（本 ADR）

- 不引入 FSRS / 完整 Anki 四按钮（可列为后续 ADR）。
- 不改变 story `reviewMode: none` 的 **阅读书签** 语义（仍不进复习池，除非词表显式「加入复习」）。
- 不改造 pack zip 协议外层（0008）；仅 App 侧调度与 UI 行为变更。

## 2. 决策概览

```text
┌─────────────────────┐    加入复习 / 暂不     ┌─────────────────────────┐
│ 学习包（各 pack）     │ ───────────────────► │ 统一复习池（虚拟，跨 pack） │
│ 全量词表 + 书签       │   幂等，按 knowledgeId │ Leitner 档位 + dueAt      │
└─────────────────────┘                       └───────────┬─────────────┘
                                                            │
                    底栏「+」Tab：仅到期复习 ◄────────────────┘
                    两按钮：记住了 / 还不熟（明天）
```

## 3. 学习包行为（Pack Browse / Learn）

### 3.1 内容范围

- **每次打开**：展示该 pack **全部** 可学词条（`cards` 全量或按课顺序），**不因**「已在复习池 / 已掌握 / 今日已学」而过滤。
- **书签**：持久化 `lastPosition`（`knowledgeId` 或 `sortOrder` + 可选 scroll 偏移）。
- **打开落点**：由用户偏好 **`packOpenPosition`** 决定（**设置页**配置，**不**每次弹窗）：
  - `bookmark`（默认）：打开 pack 时 **从书签继续**
  - `start`：打开 pack 时 **从列表顶 / 第一课开头**
- **随时可再次打开**同一 pack；书签始终更新，仅 **`packOpenPosition`** 决定默认落点。

### 3.2 用户操作（vocabulary 等可复习 cardType）

| 按钮 / 状态              | 行为                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------- |
| **加入复习**             | 池内无该词 → 见 §5.3 新建                                                             |
| **已加复习**             | 池内已有该词时的 **统一 UI 文案**（取代「加入复习」按钮样式）；**可点击**             |
| 点击 **已加复习**        | 弹出确认框，标题/主旨 **「更新复习」**；用户确认后见 §5.3「更新复习」                 |
| **暂不**（或「已掌握」） | 仅记「本包内已见过」（可选 `encounter` 表或轻量标记）；**不**写入复习池、**不**算间隔 |

**UI 约定（2026-08-06）：** 学习包内、Story 词表、搜索页等所有「加入复习」入口，已在池内的词 **统一显示「已加复习」**，不得仍显示可点的「加入复习」。

### 3.3 与 0012 `reviewMode` 的关系

| cardType        | 学习包底栏                               | 说明                                                                                  |
| --------------- | ---------------------------------------- | ------------------------------------------------------------------------------------- |
| `vocabulary`    | **加入复习 / 暂不**（取代 `sm2` 三按钮） | 本 ADR 核心变更                                                                       |
| `story_reading` | 无 SM-2；书签 + 词表可选「加入复习」     | 与 [story-reading 设计](../superpowers/specs/2026-08-02-story-reading-design.md) 对齐 |
| 未知 type       | 仍 `UnsupportedCardPanel`                | 不变                                                                                  |

**已确认（Q5）：** 保留 `reviewMode: sm2` enum 值，文档标 **deprecated**；App 行为改为「加入复习 / 暂不」两按钮，不 rename。

### 3.4 书库呈现（`libraryPresentation`）

- `study`：进度改为 **书签文案**（如「上次学到：第 N 词 / lesson X」），**不再**展示 SM-2 到期/掌握条（或改为「复习池中 N 词来自本包」— 待填）。
- `reader`：不变（Story 书签）。

## 4. 复习入口（底栏「+」Tab）

### 4.1 导航

- 胶囊底栏 **中间蓝色「+」** 改为 **复习 Tab**（图标/文案待 UI 稿：避免仍像「添加内容」）。
- **底栏角标**（Tab 图标上的小数字红点）：显示 **当前到期总数**（`inReviewPool && dueAt <= 今日结束` 的条数，时区见 §6.3）。**不**在此处展示每日限额；限额与「今日还可练几条」在 **复习 Tab 页内** 展示（§6.4）。**（2026-08-06 已确认）**
- **复习 Tab 页内**：提供 `dailyReviewLimit` 设置入口（默认 20）；可展示「今日已练 X / 限额 Y」「到期共 Z 词」等文案（UI 待稿）。
- **空状态**：引导「在学习里把不会的加入复习」。

### 4.2 复习 Session

- 仅包含 **复习池内、已到期** 的词条；排序 `dueAt ASC`（同 due 按 `knowledgeId` 稳定序 — 待填）。
- **两按钮**（揭示后或卡片正面 — 待 UI 稿）：
  - **记住了** → Leitner **升档**（§6.1）
  - **还不熟** → **明天再见**（§6.2），不区分「忘记/模糊」
- **每日复习词数**：读取用户设置 `dailyReviewLimit`（§6.4）；单次 session 从到期词中取 **不超过当日剩余额度** 的条数；**due 不变**，未练到的到期词 **仍在池中待后续天数**（不自动推迟 due）。
- **来源学习包展示（2026-08-06 已确认）**：复习 Session 中 **每条词条** 须可见 **来自哪个学习包**（展示 `installed_packs.displayName`）；数据取自该词的 `firstAddedFromPackId`（与卡面/音频来源 pack 一致）。包已卸载时降级显示 packId 或「已卸载的学习包」文案。

### 4.3 与学习包并行

- 同一 `knowledgeId` 可 **同时** 出现在学习包列表与复习 Tab；**数据一条**，展示两处。
- 学习包内已在池中的词：底栏/操作区显示 **「已加复习」**（§3.2）；可选 P1 词条角标「复习中」与按钮文案 **二选一**，MVP 以 **按钮状态** 为准。

## 5. 复习池数据模型与去重

### 5.1 唯一键

- **去重键 = `knowledgeId`**（0008 稳定 ID；跨 pack 同词必须同 ID）。
- **禁止**按 `(packId, knowledgeId)` 或词面字符串建多条复习记录。

### 5.2 建议字段（`review_pool` 或扩展 `learning_states`）

| 字段                          | 类型         | 说明                                                                                                       |
| ----------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------- |
| `knowledgeId`                 | PK           | 全局唯一                                                                                                   |
| `inReviewPool`                | bool         | 是否在池内（「暂不」Never 写 true）                                                                        |
| `boxLevel`                    | 0..3         | Leitner 档位                                                                                               |
| `dueAt`                       | ISO datetime | 下次复习时刻                                                                                               |
| `firstAddedFromPackId`        | string       | 复习卡面/音频及「来自 xxx」的 **来源 pack**；**首次**入池写入；**更新复习**（§5.3）时 **覆写为当前学习包** |
| `lastSeenInPackId`            | string?      | 最近一次在学习包点「加入复习」的 pack（可选）                                                              |
| `clientVersion` / `updatedAt` |              | 同步（对齐 0009 / sync outbox）                                                                            |

**待填：** 是否保留 `easiness` / `repetitions` 仅作迁移只读，还是删除。

### 5.3 「加入复习」与「更新复习」

| 场景                                                           | 行为                                                                                                                                                                      |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 池内 **无** 该 `knowledgeId`                                   | 创建：`inReviewPool=true`, `boxLevel=0`, `consecutiveLevel3Passes=0`, `dueAt=下一复习日锚点`（§6.3）；`firstAddedFromPackId=当前 catalogPackId`；**写入入池统计**（§5.6） |
| 池内 **已有**，用户 **仅浏览 / 误触**                          | UI 显示 **「已加复习」**；**不**自动改档位或 due                                                                                                                          |
| 池内 **已有**，用户点 **「已加复习」** 并在确认框选择 **更新** | **等价于** 从复习池删除该条后，用 **当前学习包** 的卡面与信息 **重新入池**（见下表）                                                                                      |
| 池内 **已有**，用户 **取消** 更新                              | 无数据变更                                                                                                                                                                |

**「更新复习」写库语义（2026-08-06 已确认）：**

| 字段                      | 更新后值                                                       |
| ------------------------- | -------------------------------------------------------------- |
| `inReviewPool`            | `true`（保持或在池内）                                         |
| `boxLevel`                | `0`（进度清零）                                                |
| `consecutiveLevel3Passes` | `0`                                                            |
| `dueAt`                   | 下一复习日锚点（同新入池）                                     |
| `firstAddedFromPackId`    | **当前** catalogPackId（卡面/音频/「来自 xxx」均改指向当前包） |
| `lastSeenInPackId`        | 当前 catalogPackId                                             |
| legacy SM-2 只读列        | 不依赖；可忽略                                                 |

- **不计入** `joinedPoolCount`（非首次入池；§5.6）。
- **须** 写 `sync_outbox`（与新建/评分同级）。
- MVP **不提供** 单独的「移出复习计划」按钮；**更新复习** 是唯一的「用当前包内容覆盖复习条目」路径（§5.4）。

### 5.4 移出复习池

- MVP **不提供** 独立「移出复习计划」入口。
- 用户可在学习包内通过 **「已加复习」→ 更新复习** 用 **当前包** 内容 **覆盖** 复习条目（等价删后重加，§5.3）。
- 仅通过升档到最高档 + 长间隔间接「毕业」。

### 5.5 同词不同 `knowledgeId`

- 视为 **pack 内容错误**；由 pack-builder 校验，App **不**做词面级 merge。

### 5.6 学习统计（本地记录，面板 UI 后续）

**产品决策（2026-08-06）：**

- **不限制** 每日新入池词数；用户可在学习包内任意多次「加入复习」。
- **须统计** 数据，供后续 **学习/复习面板** 展示（本 ADR 只定数据，不做面板 UI）。

**建议落库（`user.sqlite`）：**

| 存储                                    | 说明                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `review_daily_stats`                    | 按 **本地日历日**（`YYYY-MM-DD`）一行：`joinedPoolCount`（今日 **首次** 入池词数）、`reviewCompletedCount`（今日复习完成词数，可选 P1）、`reviewSessionCount`（可选 P1） |
| 或等价 **事件表** `review_stats_events` | `eventType: joined_pool \| review_completed`，`knowledgeId`，`occurredAt`；面板按日聚合                                                                                  |

**计数规则：**

- `joinedPoolCount`：**仅** §5.3 中「池内无 → 新建」时 +1；重复点「加入复习」、已在池内 **不加**。
- 跨日清零：按 §6.3 本地切日边界重置当日计数（或按日落库新行）。
- **同步**：统计默认 **本地**；是否上传服务端留待后续 ADR（MVP 面板读本地即可）。

## 6. Leitner 调度（仅复习 Tab）

### 6.1 档位与间隔（「记住了」升档后）

| boxLevel | 用户文案（建议） | 下次复习                                                                                     |
| -------- | ---------------- | -------------------------------------------------------------------------------------------- |
| 0        | 新加入           | **+1 天**                                                                                    |
| 1        | 初熟             | **+3 天**                                                                                    |
| 2        | 较熟             | **+7 天**                                                                                    |
| 3        | 熟练             | **+21 天** → 之后 **+45 天 → +90 天** 封顶（Q3 已确认；level 3 再次「记住了」按 +90 天循环） |

升档：`boxLevel = min(boxLevel + 1, 3)`，按上表从 **当前复习日** 起算 `dueAt`。

### 6.2 「还不熟」

- **统一**：`dueAt = 明日同一规则锚点**（与升档共用 §6.3 时区锚点，**非** 10 分钟后、**非** 当天 session 内重插）。
- 降档：`boxLevel = max(boxLevel - 1, 0)`；**level 0 再按「还不熟」仍保持 0**（已确认）。

### 6.3 日历锚点（待填）

- 「明天」按 **用户本地日历日** 还是 **UTC**（现行 SM-2 用 UTC，本 ADR 建议 **本地 04:00 或 0:00** 切日 — 待确认）。
- 与 `formatReviewInterval` 文案一致化。

### 6.4 每日复习词数（用户设置）

**产品决策（2026-08-06）：** 复习 Tab 当日处理 **到期** 词的数量上限由 **用户设置**，非固定常量；**入池不设每日上限**（见 §5.6 仅统计）。

**用户偏好 `dailyReviewLimit`：**

| 项       | 说明                                                           |
| -------- | -------------------------------------------------------------- |
| 存储     | `user.sqlite` 设置表或 SecureStore（与账号无关的本地偏好即可） |
| 默认值   | **20**（已确认）                                               |
| 合法范围 | 建议 **1～999**（待填硬上限）                                  |
| 设置入口 | **复习 Tab 页内**（已确认）；不设全局设置页 MVP 硬依赖         |

**Session 配额计算（每个本地日）：**

```text
remainingQuota = dailyReviewLimit - todayReviewCompletedCount
sessionSize    = min(count(due 且 inReviewPool), max(remainingQuota, 0))
```

- `todayReviewCompletedCount`：当日已在复习 Tab 完成（「记住了」或「还不熟」）的词数；完成一条 +1（可选同步写入 §5.6）。
- **到期但未进入当日 session 的词**：`dueAt` **保持不变**，仍算到期；**底栏角标**仍计入总到期数；用户提高限额或次日可继续练。
- **不**因超限额自动把 due 推到明天（与「还不熟=明天」区分）。

## 10. 验收门禁（待填用例）

- [ ] 学习包：全量词可见；杀进程后书签恢复；「暂不」不进池；`packOpenPosition` 在设置页切换后落点正确。
- [ ] 同词在两 pack：首次「加入复习」仅一条；已在池显示 **「已加复习」**；确认 **更新复习** 后档位清零且来源包改为当前包。
- [ ] 复习 Tab：仅到期词；「还不熟」→ 明日；「记住了」→ 间隔符合档位表；**每条显示来源学习包名称**。
- [ ] 用户修改 `dailyReviewLimit` 后，当日 session 条数符合配额；due 超额词仍保持到期。
- [ ] 今日 **首次** 入池计数正确；重复点「已加复习」不增加计数；**更新复习** 亦不增加计数。
- [ ] 底栏角标 = 总到期数；复习 Tab 页内展示限额与今日进度（§4.1 / §6.4）。
- [ ] 跨天、本地时区「明天」正确。
- [ ] 同步：双机加入复习 / 复习升档不丢、不重复。
- [ ] Story 词表加入复习与 vocabulary 进同一池。
