# 代码形态规则

## 文件职责

- 一个文件只有一个可用一句话说明的主要职责。
- 一个业务文件原则上只有一个主要导出组件、类、Hook或用例。
- 文件名直接表达主要职责。
- `index.ts`只做公开导出，不放业务逻辑。
- 禁止以 `utils.ts`、`helpers.ts`、`common.ts`、`misc.ts`作为代码垃圾桶。
- 共享代码按真实职责命名，不因“以后可能复用”提前抽象。
- 超过250行时检查职责并在交付中解释。
- 超过400行的人工维护源码默认禁止合并。
- 自动生成文件、迁移、测试数据和纯声明配置可例外，但须标明来源。
- 禁止压缩格式、删除必要注释或使用超长表达式规避限制。

## 命名

标识符使用简单、准确的英文，不使用拼音。优先选择中国小学生可以理解的常用单词；必要业务术语写入 `words.md`。

- 文件与目录：`kebab-case`。
- 函数与变量：`camelCase`。
- React组件、类和类型：`PascalCase`。
- 局部常量：`camelCase`；真正跨模块且不可变的常量：`UPPER_SNAKE_CASE`。
- 布尔值：`is`、`has`、`can`、`should`开头。
- Hook：`use`开头。
- 组件事件属性：`onXxx`；内部处理函数：`handleXxx`。
- 函数使用“动词+业务对象”，禁止 `processData`、`doWork`、`handleThing`等模糊名称。
- 缩写按普通单词处理，如 `userId`、`apiClient`、`smsCode`、`packUrl`。

查询动词：

- `findXxx`：允许找不到。
- `getXxx`：必须存在，找不到返回明确错误。
- `listXxx`：返回集合。
- `fetchXxx`：通过网络获取。
- `readXxx`：从本地文件或数据库读取。
- `create/update/delete`：产生持久化修改。
- `calculate/build/normalize/validate`：用于无外部副作用的逻辑。

## 函数

- 一个函数完成一个简单动词短语可以描述的任务。
- 普通函数超过40行必须检查拆分，超过80行默认禁止。
- React组件超过120行必须拆分展示或业务逻辑。
- 嵌套最多3层，优先提前返回。
- 参数最多3个；更多参数使用有明确类型的对象。
- 禁止多个布尔参数控制不同模式。
- 禁止修改传入对象和数组。
- 领域计算尽量使用纯函数；IO放在外层用例。
- 对外导出函数显式声明参数和返回类型。
- 禁止 `any`；外部数据以 `unknown`进入，验证后使用。
- 同时包含读取、计算、写入和通知的函数必须拆成用例编排和独立步骤。

## 注释

标识符用英文，注释和工程说明优先使用简洁中文。注释解释“为什么”，不翻译代码。

必须解释事务、锁、幂等、安全边界、不能删除的兼容逻辑、不直观的调度与状态转换、第三方SDK限制、过渡设计删除条件、复杂SQL和正则。

`FORBIDDEN`：

- 注释逐字翻译代码。
- 用注释掩盖命名不清或函数过长。
- 保留被注释掉的旧代码。
- 记录Git已有的修改历史。
- 合并无跟踪编号的 `TODO`、`FIXME`、`HACK`。
- 机械生成无信息量TSDoc。

架构原因写入架构决策；代码只保留简短原因和文档链接。

## React

- 页面只组合界面、读取页面状态和触发用例。
- 组件不得直接访问SQLite、HTTP、Keystore或文件系统。
- 数据访问通过明确Hook或应用用例。
- 状态放在最接近使用位置，确有跨页面共享时才提升。
- 禁止万能全局Store。
- 服务器数据、学习会话和纯界面状态分开。
- 可计算值不重复存储。
- `useEffect`只同步外部系统，不代替事件处理或派生计算。
- 禁止在渲染函数内声明子组件。
- 长列表使用稳定业务ID，禁止数组下标Key。
- 可复用组件在真实重复后提取，不提前建设万能组件库。
- 移动端与后台共享契约和设计符号，不共享页面组件。
- 状态管理库不提前引入。

## 状态与异步

- 订单、支付、下载、同步和学习任务使用明确状态机，不使用多个布尔值拼凑状态。
- 状态转换集中管理并测试非法转换。
- 数据库事务内不执行长时间网络请求。
- 网络请求具有超时、取消或卸载清理。
- 只有幂等操作自动重试，并限制次数和采用退避。
- 禁止无上限 `Promise.all`、无限重试和无清理定时器。
- 同时只下载一个完整学习包。
- 相同点词音频并发请求合并。
- 同步批次可重复提交，结果由版本和唯一标识保证一致。
- 组件卸载后不更新界面状态。
- 异步失败进入明确失败状态，不能永久加载。
